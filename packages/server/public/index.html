Use the CLI, Claude Code and local MCP clients, including Codex, or add the hosted connector to Claude or ChatGPT web. Copy the endpoint and find setup steps in Install. Account and workspace policies apply.

Know your privacy mode

Local encryption. Or hosted convenience.

Local mode: the CLI, plugins and local MCP encrypt questions and answers on your devices. The phone link's key stays after #, which browsers do not send to the server. Local clients never send that key to Grill Me.

Hosted app mode: the model passes the private link back to our connector. Grill Me handles the key and readable questions or answers transiently in memory to encrypt/decrypt them; they are not stored readable or logged. Your model/provider also sees the conversation and private link. Treat the full link as private: anyone with it can read and answer.

In either mode the relay keeps only the current encrypted round and uncollected answers. Acknowledgement clears those ciphertexts; it keeps no interview history. Publishing a round, submitting answers or acknowledging collection refreshes a one-hour expiry. A minimal ID, end reason and expiry receipt lasts up to ten minutes so an open phone can distinguish finishing, cancellation and expiry. Optional answer-ready callbacks retain bounded delivery metadata and encrypted callback configuration, never the interview's questions, answers or history.

The phone keeps the current key and unconfirmed draft locally for reloads; previous-round plaintext is cleared on confirmed transitions, and session state is purged when it ends. An offline browser cannot learn an ending until it reconnects. This homepage demo uses memory only.
